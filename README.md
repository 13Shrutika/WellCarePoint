# WellCarePoint
**WellCarePoint - Healthcare Management System**
Overview

WellCarePoint is a full-stack Healthcare Management System developed to simplify interactions between patients and doctors. The application provides a centralized platform for appointment scheduling, patient management, doctor management, and medical record tracking.

The system is designed to improve healthcare service accessibility by allowing patients to book appointments online while enabling doctors and administrators to efficiently manage healthcare operations.

**Project Objectives**
- Provide an easy-to-use healthcare management platform.
- Enable online appointment booking for patients.
- Allow doctors to manage patient appointments effectively.
- Maintain patient medical records digitally.
- Improve communication and scheduling between patients and healthcare providers.
- Reduce manual paperwork and streamline healthcare processes.

**Patient Module**
- Patient Registration and Login
- View Personal Dashboard
- Book Appointments with Doctors
- View Appointment History
- Access Medical Records
- Manage Personal Information
**Doctor Module**
- Doctor Registration and Login
- View Scheduled Appointments
- Manage Patient Appointments
- Access Patient Medical Records
- Monitor Daily Consultation Schedule
